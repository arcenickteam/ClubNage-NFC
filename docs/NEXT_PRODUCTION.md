# Production roadmap

1. Real central authentication for club staff.
2. Central database with members, groups, schedules, sessions and attendance events.
3. Offline queue + conflict-safe synchronization across several phones.
4. Admin role and badge assignment workflow.
5. OneDrive/Excel export through Microsoft Graph where the club account supports the required workbook APIs.
6. Audit log, retention policy and privacy controls suitable for a children's sports club.
7. Automated tests for NFC mapping, duplicate scans, wrong-group scans and offline synchronization.
