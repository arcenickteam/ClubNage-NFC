# Premier test Samsung A33 5G

1. Installer l'APK `app-release.apk`.
2. Vérifier que le NFC est activé dans les réglages du téléphone.
3. Ouvrir ClubNage NFC.
4. Choisir une séance de démonstration.
5. Appuyer sur **Scanner NFC**.
6. Approcher un porte-clé NTAG213 de la zone NFC du dos du A33.
7. Vérifier que l'UID est lu et que la présence est enregistrée.

Le premier test doit être réalisé avec un badge de test et des nageurs fictifs.
